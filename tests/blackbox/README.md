# 浏览器黑盒测试

通过 Playwright 启动独立 Chrome 会话，点击真实页面、选择虚构材料文件夹、检查页面和公开 HTTP 请求。不导入前端内部模块，也不接触日常浏览器配置或真实签证材料。

## 运行

先启动项目后端，再执行：

```sh
cd tests/blackbox
npm ci
npm test
# 显示浏览器操作过程
npm run test:headed
```

默认访问 `http://127.0.0.1:8000`，使用已安装的 Google Chrome。可通过 `BLACKBOX_BASE_URL` 改测试服务器，`BLACKBOX_BROWSER=msedge` 改用已安装的 Edge。不要指向生产环境：发送测试会真实调用审核接口，测试服务必须设置 `LOG_ONLY=1`，避免产生模型费用。

## 覆盖范围

- 清单正常加载、重试按钮隐藏、桌面布局不溢出。
- 网络失败三次后手动重试（仅此用例模拟网络故障）。
- 文件夹选择、系统文件过滤、自动预处理、本地规则运行及步骤解锁。
- JPG 预处理流程、隐私页卡切换、拖动虚线框、松开打码和撤销。
- 全部确认后发送脱敏副本、检查请求没有原文件名并显示审核报告。
- 重新开始清空工作区。

测试串行运行，避免同时争抢 OCR 资源。JPG 用例运行真实预处理和本地 OCR 调用，不模拟识别结果；该用例验证手动脱敏流程，不断言 OCR 文字结果或自动隐私识别的准确性。虚构文件使用专属临时目录，测试结束删除；前端调试日志在测试浏览器内拦截，不污染日常服务日志。

失败截图、trace 和 HTML 报告位于本目录被 Git 忽略的输出目录，仅包含虚构数据。浏览器上下文在每个测试后销毁。测试通过不代表真实审核规则已经完备；PDF、多页混合材料、性能上限等可继续补充。
