# Knowledge Agent

该目录是知识库与 Agent 的后台业务边界，未来接收材料风险审核请求，检索对应国家、签证
类型和材料类型的知识，并返回带来源证据的风险判断。

当前只创建模块占位，不提前确定内部子目录和具体技术实现。

约束：

- 不接收用户原始签证材料；
- 输入仅包含本地隐私处理后的最小化结构化事实；
- 官方规则、专业解释和个人经验必须区分来源等级；
- 风险结论必须带证据，经验信息不能直接导致官方审核项 `FAIL`。

详细方案见 [`../../../docs/material-audit-data-architecture.md`](../../../docs/material-audit-data-architecture.md)。
