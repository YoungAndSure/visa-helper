# 欧盟通用要求：本地测试种子

来源：[欧盟委员会的申根签证申请概览](https://home-affairs.ec.europa.eu/policies/schengen/visa-policy/applying-schengen-visa_en)，核对日期 2026-09-12。

`source.json` 保存网页地址、来源栏目和经核对的中文摘要，不是全文抓取副本。
整理与规则转换由本次开发完成，不是后台 LLM 生成；后台目录自动生成仍是另一条独立流程。

本轮选取六项材料要求，用于验证已有规则驱动框架。仅映射当前测试场景 `IS / schengen-tourism`，
未推定其他国家规则库、未覆盖特殊家庭成员等豁免，也不替代冰岛驻当地使领馆清单。
规则标题都标有“通用测试”，存在性检查通过不等于完整合规。个人身份、财力是否充足等不在范围内。

## 安装

从仓库根目录执行：

```sh
backend/.venv/bin/python tools/rules/bootstrap_general.py
```

首次安装将经核对的六条规则发布到本机规则库；已存在相同版本则不重复写入。
如果已有其他活动规则，命令拒绝覆盖；可用 `--store <独立目录>` 测试。
运行产物仍不进入 Git，来源记录、转换代码和测试会入库；其他机器可以用同一命令重现。

后端每次审核重新加载活动规则，无需重启。前端“要求清单”仍展示原有完整 Checklist，
而远端报告执行这六条子集，两者并非同一个列表。

## 测试边界

自动测试检查来源哈希、六条规则发布/读取、逐规则编排和不覆盖已有规则，不证明模型判定准确率。
当前本机服务仍为 `LOG_ONLY=1`，点击远端审核会显示六条未执行（skipped/WARNING），不会产生假通过。
真实判断需要先配置并启用支持 PDF/JPG 的模型，再用用户确认的脱敏文件测试。
