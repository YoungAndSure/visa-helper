# 官方表格预填：冰岛申根申请表

## 产品方式

申请表仍是清单中的一个独立任务，整理资料、填写、检查及签字确认属于同一任务。默认优先由GPT从对话或用户愿意提供的资料中整理已确认信息，MCP生成预填好的官方原PDF，用户下载后补齐、核对、打印并签字。也保留“按提示自己填写”：随时取得空白原表与HTML填写说明，不要求提供个人字段或上传。

生成可先于资料收集完毕。已知且可写入的项预填，未知或不适用的项留空，不自动写“否”或“不适用”。输出始终标记partial；不能因文件已生成就宣称全部适用必填项已完成。照片、声明阅读、地点与实际签署日期、本人或适用监护人签字仍由用户处理。完成条件沿用原任务：用户确认填妥、完成自查或自愿辅助检查、确认签字。

官网在线申请另待具体示例验证，本次没有实现官网填表或DOCX生成。其他材料既有HTML草稿仍保留。

## 表格分别维护

- `app/config/forms/schengen-en-cn-2025-03.pdf`：随镜像发布的官方空白原表，4页，不在用户下载时临时抓取。
- `app/config/forms/iceland-schengen-en-cn-2025-03.json`：当前表格专属映射。77个逻辑填写项覆盖86个原生PDF字段，分别配置字段ID、原PDF名称、选项实际值、页码、适用提示。
- `app/src/schengen-pdf.js`：本表的值解析、字段映射与PDF生成。使用MIT开源库pdf-lib 1.17.1；保留可编辑字段，更新打印外观，不重画官方正文或代替用户签字。

原表来源：[VFS官方PDF](https://www.vfsglobal.com/one-pager/iceland/china/chinese/pdf/Schengen-Visa-Form-EN-CN-Mar-2025.pdf)。原文件SHA-256为 `c415e3103fcf878d2a817e70cb27f2d46fe971c34618bfa23ac31aad6d43b072`。源文件和映射分别带指纹，并计入服务构建指纹及自动回归契约。官方原表的单选框导出标签存在重复，按核对过的实际widget值选择，覆盖性别等所有单选项回归。

后续每份表格独立维护原文件、字段映射、适用条件、特殊处理及测试。能够共用文件传输、临时链接、任务状态保存和PDF库调用，不强行复用不同表格的业务映射或官网操作步骤。

## GPT 与 MCP

沿用 `start_task` / `advance_task`，不增加工具。

1. 选择 `schengen_form`，取得 `taskFlow.fieldCatalog`。`pdf:true` 项为可预填字段，包含具体问题含义和规范选项；`prefill.fields`返回相应字段值与状态。
2. 优先使用已确认信息。现国籍、现居情况、旅游目的、明确的单一目的地与抵离日期可复用第一阶段答案；首入国、入境次数、姓名、出生国等不猜测。
3. 按原表分组和适用条件收集缺项。欧洲家庭成员、邀请机构、资助及非本人填表资料先确认适用性，不把77个项目盲目全部询问。用户可随时先下载部分预填文件。
4. 用 `advance_task` 提交完整 `data.fields`，其余checks、review等完整保留。细分字段如 `19.phone`、`30.address`、`32.self.creditCard` 与原有字段放在同一快照；不存在第二套答案。
5. `data.fillMode` 为可选的assisted/manual，不提供时按assisted展示。用户选manual时保存manual，改用原表和HTML说明；再次选assisted恢复预填。旧快照无该属性仍能读写和回放。
6. 默认预填阶段返回 `nextAction.type=prepare_form`，包含当前业务动作和生成的PDF信息；manual沿用open_url与HTML说明。生成不触发FILLED或FINISH。GUIDE_READY仍只表示可用指引/部分文件已准备好。

`formDocument` 为模型可见结果，包含url、expiresAt、mimeType、filename、partial、filledCount、writtenFieldIds及issues。移除私有_meta也可取得下载链接。无法编码的文字、超出可读空间的长内容、无法识别的选项及旧版汇总内容均明确报issue，不默默截断或猜选；用户/GPT修正后提交完整快照重新生成。未填写项目可在HTML查看说明。

原有17/29/32/33汇总字段保留作历史参考，预填使用细分字段，汇总文本不会直接灌入某一个不对应的格子。填写姓名遵循护照，原表要求英文；不擅自猜拼音。标准宿主提供下载通道，兼容宿主保留可打开、可另存的PDF链接。

## 保存与文件链接

现有XState准备/填写/检查骨架和完成条件不变；填写模式及细分字段随同一任务快照持久化，暂停与恢复保留。PDF渲染器与原表映射独立版本化，旧任务模型与执行历史指纹不改。单项任务仍按taskId隔离；其他材料不接受本表细分字段。

公网页面监听器新增只读 `/forms/<随机令牌>/application.pdf`，与原 `/guides/` 共用服务但不开放MCP。链接15分钟有效、无缓存、不含申请编号；申请或任务revision变化后旧链接失效。文件仅在有界内存缓存中短暂保存，过期清理；模型收到的是链接和结构化状态，不返回PDF的base64正文。磁盘申请快照仍只存结构化字段及历史，不另存生成PDF。

## 回归与维护

测试使用虚构资料：原表4页与86字段清点、77项映射、所有单选选项与唯一选中、文字与日期、目的多选、资金选项、未知留空、字段可继续编辑、错误提示、临时链接过期及修改失效、两种模式保存恢复和历史回放。标准/兼容桥真实Chromium检查页卡入口、打开PDF、下载或另存提示、模式切换及原有任务导航。

`app/test/support/task-scenarios.mjs`增加两种填写模式继续到检查完成的场景，明确生成不等于签字或检查。流程契约增加有效字段目录和模板指纹，新增或改动映射必须审查契约差异；26张现有XState图的节点与跳转不变。真实GPT的资料提取、用户确认及所有PDF阅读器的行为仍须实际验收。

运行完整回归：`npm run test:regression --prefix app`。模板有意更新时先补场景，再更新并审查契约，最后重新打包镜像部署。
